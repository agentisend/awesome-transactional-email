# Contributing

Suggestions and corrections are welcome as issues or pull requests.

- One entry per pull request, in alphabetical order within its section.
- Format: `- [Name](link) - Description.` The description starts with a capital letter, ends with a period, and says what the thing is, not how good it is.
- Link the project's own website or repository.
- No archived, unmaintained or undocumented projects.
- Disclose it if you work on the project you add.
- Cold outreach and bulk prospecting tools are out of scope: this list is for mail people asked for.
